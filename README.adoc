== What is this?

The {plugin-title} plugin assigns and removes IEC 61850 GOOSE and sampled value
supervisions in an SCL file.

The plugin creates, assigns, disconnects and deletes supervision logical nodes
of the classes `LGOS` and `LSVS`.

The plugin uses the OpenSCD plugin API.
Add it to the `editor` plugins of a distribution.
Refer to the {uri-docs}[documentation].

== Try it

Open the {uri-demo}[online demo].
The demo opens a sample SCL file.

Install the package from {uri-npm}[npm]:

 $ npm i oscd-editor-supervision

== Development

 $ npm i
 $ npm start

Open http://localhost:8000/demo/ in a browser.

Run the checks:

 $ npm run lint
 $ npm test

Refer to the development page in the {uri-docs}[documentation] for the build,
the tests, the screenshot baselines and the release.
